# Главная — утверждённый дизайн (19.10.2026)

Порядок сверху вниз:
1. Шапка: логотип Duo (два контурных сердца на шалфейном градиенте, скруглённый квадрат) + имена «Вероника и Максим» (Lora) + строка настроения партнёра «Максим: спокойно» с зелёной точкой.
2. 4 круглые кнопки: Думаю о тебе (акцентная, залитая) · Настроение · Кино · Желания. Подписи ровно в 2 строки.
3. Две плитки одной высоты:
   - слева — градиент «Вместе / 346 дней» с полупрозрачным сердцем;
   - справа — кольцо прогресса до ближайшей важной даты, число дней ВНУТРИ кольца, рядом заголовок даты («1 год», «ДР Максима» — без слова «вместе») и подпись с правильным склонением: «остался день» (1, 21…), «осталось дня» (2–4, 22–24…), «осталось дней» (остальное); в сам день — сердце в полном кольце и «сегодня». Нажатие → окно со всеми важными датами (добавить/удалить).
4. Карточка дня: заголовок «Сегодня» / «Среда, 21 октября» + ссылка «План ›»; полоса недели Пн–Вс (выбранный день светло-зелёный #c3dfcb с тёмным текстом, точки: зелёная — события, золотая — даты); список дел выбранного дня (время + цветная полоска + название + подпись).
5. Вопрос дня: золотистая карточка, метка «ВОПРОС ДНЯ», текст курсивом Lora, внизу статус («Максим: ответ готов») + кнопка «Ответить»; после ответов обоих — ответы внутри карточки.

Убрано: длинный список «Важные даты» и «Скоро в календаре» (дублировали друг друга).
